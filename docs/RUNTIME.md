# no-kalbak 실행 안내

던전앤파이터 장비 툴팁 인식 및 능력치 비교 프로그램의 Windows x64 배포판입니다.

## 준비

- Windows 10 2004(빌드 19041) 이상, x64
- 한국어 Windows OCR 언어 구성요소
- 본인의 Neople Open API 키

.NET 런타임은 실행 파일에 포함되어 있습니다.

## 실행 방법

1. ZIP을 쓰기 가능한 폴더에 전체 압축 해제합니다.
2. `config.json.sample`을 `config.json`으로 복사합니다.
3. 아래 빈 문자열 자리에 본인의 API 키를 입력합니다.

```json
{
  "apiKey": ""
}
```

4. `DnfItemChecker.App.exe`를 실행합니다.

환경 변수로 설정해도 됩니다.

```powershell
$env:NEOPLE_API_KEY = "본인의 API 키"
.\DnfItemChecker.App.exe
```

`models/`의 ONNX 모델 3개와 사전 1개는 실행 파일 옆에 계속 두세요.
`stattable.json`은 비교에 사용하는 기준 능력치 표입니다.

## 사용 흐름

캐릭터를 선택하고 장비 조회 또는 인게임 인식을 사용합니다.
착용 장비 등록 시에는 게임 장비창에서 실제 착용 아이템에 직접 마우스를 올립니다.
인식 결과를 확인한 후 저장하세요. 게임의 비교 툴팁을 켤 필요는 없습니다.

전체화면에서도 인식할 수 있습니다. 창 모드에서는 게임 화면을 클릭해 활성화해야 합니다.
다른 창을 클릭했다면 게임 화면을 다시 클릭한 후 인식할 장비에 마우스를 올리세요.

“이계의 기운이 서린” 장비는 현재 인식되지 않습니다.

## 개인 파일

실행 후 생기는 `config.json`, `dnfitems.db`, 로그 및 `debug_captures/`에는 개인 설정이나 사용 기록이 포함될 수 있습니다.
이 폴더를 통째로 다시 배포하지 말고, 소스 저장소의 `build.ps1`로 만든 깨끗한 ZIP을 사용하세요.

프로그램이 시작되지 않거나 OCR이 동작하지 않으면 `error.log`, `onnx_init.log`와 모델 폴더를 확인하세요.
한국어 OCR 구성요소가 없는 환경에서는 인식 정확도가 달라질 수 있습니다.

아직 개발 중인 기준 버전입니다. 인식 정확도와 지연은 게임 화면·DPI·해상도에 따라 달라집니다.
